# Personal coding defaults

- Read repository guidance before changing files.
- Preserve unrelated user changes and stop before overwriting them.
- Make the smallest direct change that solves the request.
- Use temporary directories for experiments and generated state.
- Run the relevant formatter, linter, type check, or test after editing.
- Keep credentials, sessions, caches, and generated dependency directories out of Git.
- Treat destructive commands, external messages, and account changes as requiring explicit user intent.
- Report the files changed and the checks that actually ran.
